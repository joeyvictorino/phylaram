# Capturing a Physical Hardware Screenshot for PhylaRAM

To ensure complete honesty and transparency, screenshots of the PhylaRAM GUI in the repository should ideally be captured from a live Windows 10/11 physical test system.

---

## Screenshot Capture Guidelines

1. **Environment:**
   - Windows 11 (22H2/23H2/24H2) or Windows 10 (21H2/22H2) x64.
   - Clean desktop wallpaper without personal or identifying information.
2. **Window Framing:**
   - PhylaRAM GUI centered on the screen.
   - Native Windows 11 DWM dark title bar and rounded corners clearly visible.
3. **Display State:**
   - Either **Ready** state (showing validated System DTB, Kernel Base, and Memory Topology) or an **Active / Finalized** state.
   - Path input set to a standard sanitized evidence path (e.g. `C:\Evidence\mem_HOST_20260823.raw`).
4. **Resolution:**
   - High-DPI capture (100% or 150% scaling), 16:9 or 16:10 aspect ratio.
   - Saved as PNG or lossless WebP in `docs/media/gui_screenshot.png`.
